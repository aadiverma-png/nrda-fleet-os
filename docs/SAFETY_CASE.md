# Safety case (simulation-grade)

This document maps each hazard to the layers that mitigate it and to the evidence. It targets the structure of ISO 3691-4 (driverless industrial trucks), but it is **not** a certification claim. The system runs in simulation.

> **Evidence status.** The unit and integration suite that this table used to cite (`core/tests/`) has been deleted, together with the two-lane `sim/aisle_sim.py` harness and the scenario benchmark (`benchmarks/`). Every mitigation below is still implemented in the runtime, and the independent `safety_monitor` still runs, but **no mitigation in this table is covered by an automated test in this tree**, and the S1-S6 scenario runs can no longer be reproduced from it. The "Evidence" column now records only what can still be produced from this repository. Until the suite is restored, this document states intent and runtime behaviour, not verified behaviour.

| Hazard | Mitigations (outermost first) | Evidence |
|---|---|---|
| Robot–robot collision in a lane | L3 space-time claims with τ = 1.0 s and a 0.35 m space margin. ORCA-DD speed scaling for same-lane neighbours. L1 probabilistic risk brake. L1 lidar protective field and hard stop | `safety_monitor` ground-truth overlap in live runs. The benchmark collision counts went with `benchmarks/`. *Suite and benchmark deleted* |
| Head-on standoff / gridlock in narrow single-file corridors (e.g. Corridor `VE`, $w < 1.05\text{ m}$) | Structural one-way lane enforcement (`is_lane_enabled` on `VE/A`); legal hold prohibition inside corridors (`_is_legal_hold`); DRP single-file standoff recognition assigning opposing loser to dynamic reroute (`single_file_standoff`) | Live stress runs (`./nrda.sh sim scenario:=busy`). The classification and reroute cover, and the 1,892-station-pair reachability check, went with the suite. *Suite deleted* |
| Collision at intersections | Claims cover every lane cell the body sweeps, including turns in place. Robots never stop inside a crossing core. The rotation guard stops a turn if a return is inside the swept body | `scheduler._is_legal_hold`, `claims` swept-band cover; live runs only. *Suite deleted* |
| Collision with racks or walls | Lanes and turns validated against every collision box with the real footprint (5 cm and 3 cm margins). Station manoeuvres validated by sweep. Lidar safety stop | `site`/`lane_graph` validation runs at graph build (CI smoke check); the margin assertions went with the suite. *Suite deleted* |
| Unmapped obstacle (dropped pallet, person) | Lidar clusters that are not in the static map and not a known peer become fleet-wide obstacles (claims blocked). L2 bypass, re-route or hold. Lidar hard stop at 0.28 m | Live runs; `perception` + `bypass` runtime path. Benchmark S3 went with `benchmarks/`. *Suite and benchmark deleted* |
| Oncoming traffic during a bypass | The visison planner claims the oncoming-lane window atomically. The window is re-checked every tick until the lane change starts. Oncoming robots schedule around the claim | **Evidence gap:** the atomic window claim, the per-tick re-check and the reserved-cell behaviour were covered by `test_controller`, `test_planner` and `test_borrowed_cells_are_not_disturbed`, all deleted. Nothing exercises them. *Suite deleted* |
| Robot failure (stops, silent) | Heartbeat timeout of 3 s. Its claims are dropped except the cells its body covers, which stay blocked. Its tasks are re-auctioned. Others bypass or re-route | **Evidence gap:** benchmark S5 was the only cover, and it went with `benchmarks/`. Live runs can reproduce it by hand (*Simulate a motor fault* in the console). *Suite and benchmark deleted* |
| Communication loss | Claims are only used once confirmed while a peer is within race distance. Stale peers are handled as static. Lidar layers are independent of communication | **Evidence gap:** benchmark S4 was the only cover, and it went with `benchmarks/`. *Benchmark deleted* |
| Two writers commanding one robot | Single-writer architecture (`MotionArbiter`). Start-up check for other `/AMR_i/cmd_vel` publishers. Nav2, RMF and the old nodes were removed from the workspace | `edge_agent_node._check_single_writer` start-up check; live runs. *Suite deleted* |
| Operator needs to stop the fleet | Latched `/fleet/control` e-stop has OPERATOR priority in every arbiter and survives gateway loss. Per-robot pause and e-stop | Live runs; latched `/fleet/control` path in every arbiter. *Suite deleted* |
| Remote actuation or spoofed directives | Directives never actuate: the receiving arbiter decides. Optional API token. SROS2 recommended for deployment | `MotionArbiter` is the only actuation path by construction. *Suite deleted* |

**Independent monitoring.** `safety_monitor` detects collisions from ground truth (footprint overlap) and physical contacts (chassis sensor). It records near misses (gap below 10 cm while closing) and stores every event in `~/.nrda/events.db`. By default it pauses the robots involved in a collision (`on_collision:=stop_pair`).
